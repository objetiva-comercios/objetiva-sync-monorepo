## Terminal Diff Output Contract

This is the only "UI" Phase 25 produces. Used by `npm run regenerate-schemas:dry-run`.

### Color Semantics (ANSI terminal — chalk v5.6.2)

| Signal | Color | chalk method | Meaning |
|--------|-------|-------------|---------|
| Added field | Green | `chalk.green('+')` | New column detected in PostgreSQL, not yet in local schema |
| Removed field | Red | `chalk.red('-')` | Column removed from PostgreSQL, still present in local schema |
| Modified field | Yellow | `chalk.yellow('~')` | Column type, nullable, or default changed |
| Unchanged | No color | plain text | Existing field with no change |
| Summary line | Bold white | `chalk.bold()` | "N changes in M entities" |
| Error | Red + bold | `chalk.red.bold()` | Fatal error, process exits 1 |
| Success | Green + bold | `chalk.green.bold()` | "All schemas updated" |

### Diff Format

```
[entity name]                          ← section header, bold
  + newColumn (varchar, nullable)      ← green
  - droppedColumn (integer)            ← red
  ~ existingColumn: int → bigint       ← yellow

Summary: 3 changes in 2 entities      ← bold white, final line
```

**Rules:**
- Group changes by entity. One blank line between entity sections.
- Each field line indented 2 spaces.
- Type changes display as `oldType → newType`.
- Summary line always present, even if 0 changes ("No changes detected").
- Dry-run output ends with: "Dry-run complete. No files written." (plain text).

### Log Level Contract (207 Fix — D-06)

| Condition | Log level | Message |
|-----------|-----------|---------|
| HTTP 207, errors.length === 0 | `info` | "[XxxClient] Batch exitoso, sin errores" |
| HTTP 207, errors.length > 0 | `warn` | "[XxxClient] Batch con exito parcial (207 Multi-Status)" |

This is pino logger output (JSON structured), not terminal styling. No chalk involved.
