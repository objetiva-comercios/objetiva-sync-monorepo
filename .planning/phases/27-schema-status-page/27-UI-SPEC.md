## Color

All values use CSS custom property tokens defined in `src/index.css`.

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `hsl(var(--background))` — `222 20% 8%` | Page background, `gradient-bg grid-pattern` wrapper |
| Secondary (30%) | `hsl(var(--card))` — `222 20% 11%` | Table container card, entity tab bar background, column header rows |
| Accent (10%) | `hsl(var(--primary))` — `200 100% 50%` (cyan) | Active tab underline indicator, page title gradient, "Refresh" button ring |
| Destructive | `hsl(var(--destructive))` — `0 84% 60%` (red) | Mismatch status indicator dot and row tint only |

Accent reserved for: active tab selection indicator, page title gradient text. Do NOT apply to table rows, badges, or field status indicators — those use semantic alignment colors below.

## Component Inventory

### New Components

**`SchemaStatus.tsx`** — Page root component
- Wraps `useSchemaComparison` hook
- Renders loading state (spinner + "Cargando schemas..." — matches Dashboard loading copy pattern)
- Renders error state (AlertCircle + error message + "Reintentar" button — identical pattern to Dashboard.tsx)
- Renders `sync_reported: false` banner (informational, not blocking)
- Renders entity tabs row + comparison table

**`useSchemaComparison.ts`** — Data hook
- Fetch-on-mount to `GET /api/schemas/compare` with JWT auth header
- Poll interval: 10 000ms (5x slower than useGatewayData — schema data is stable)
- Returns: `{ data: EntityComparison[] | null, isLoading: boolean, error: string | null, refresh: () => void }`

**`SchemaEntityTabs.tsx`** — Horizontal entity tab switcher
- Props: `entities: EntityComparison[]`, `activeEntity: string`, `onSelect: (entity: string) => void`
- Each tab: entity name + summary badge (mismatch + missing count, or green checkmark when both are 0)
- Active tab: bottom border `border-primary` 2px, text `text-primary`
- Inactive tab: `text-muted-foreground`, hover `text-foreground`

**`SchemaComparisonTable.tsx`** — Per-entity comparison table
- Props: `comparison: EntityComparison`, `syncReported: boolean`
- Columns: Field Name | PostgreSQL | Compiled | Sync | Status
- Each layer sub-cell: `data_type` in `font-mono text-sm`, `is_nullable` as `YES`/`NO` in `text-xs text-muted-foreground`
- Missing layer: `—` placeholder in `text-muted-foreground`
- Status cell: colored dot (6px circle, `rounded-full`, `inline-block`) + status text label

**`SyncNotReportedBanner.tsx`** — Inline informational banner
- Shown when `sync_reported === false` for any entity
- Style: `bg-yellow-500/10 border border-yellow-500/30 rounded-lg p-3`
- Icon: `AlertTriangle` (Lucide, `text-yellow-400`, `w-4 h-4`)
- Copy: "Sync no ha reportado schemas al gateway. Los datos de la columna Sync no están disponibles."
- Not blocking — table still renders with `—` in Sync column

### Reused Components

- `ui/card.tsx` — wraps table, entity tabs section
- Loading/error pattern from `Dashboard.tsx` — copy verbatim, update copy strings
- Lucide icons: `CheckCircle2` (aligned), `XCircle` (mismatched), `AlertTriangle` (missing + banner), `RefreshCw` (loading + refresh button), `Database` (page header icon)

### Navigation Change: `App.tsx`

Add tab bar at top level. State: `const [activeTab, setActiveTab] = useState<'dashboard' | 'schema'>('dashboard')`.

Tab bar: two tabs — "Dashboard" and "Schema Status". Same visual treatment as `SchemaEntityTabs` but at page level. The tab bar sits above the page content, below the viewport top edge, full width.

## Interaction Contracts

### Tab Navigation (page-level)
- Click "Dashboard" tab → renders `<Dashboard />`, hides `<SchemaStatus />`
- Click "Schema Status" tab → renders `<SchemaStatus />`, hides `<Dashboard />`
- No animation between tabs — immediate conditional render (consistent with existing pattern)
- Active tab: `border-b-2 border-primary text-primary font-semibold`
- Inactive tab: `text-muted-foreground hover:text-foreground transition-colors`

### Entity Tab Switching (within Schema Status page)
- Click entity tab → updates `activeEntity` state → table re-renders with new entity's data
- No animation — immediate re-render
- Default selected: first entity in API response (`articulos`)
- Entity tab summary badge: show count only when `mismatched + missing > 0`, show `CheckCircle2` icon (emerald) when count is 0

### Refresh
- Manual refresh button in Schema Status header: `RefreshCw` icon + "Actualizar" label
- Calls `refresh()` from `useSchemaComparison`
- Button shows `animate-spin` on `RefreshCw` while `isLoading === true`

### Loading State
- Full-page spinner (same as Dashboard): `RefreshCw` w-16 h-16 `text-primary animate-spin` centered
- Copy: "Cargando schemas..."

### Error State
- Same pattern as Dashboard: `AlertCircle` w-16 h-16 `text-red-400` centered, error message, "Reintentar" button
- Button: `px-4 py-2 bg-primary text-primary-foreground rounded-lg hover:opacity-90 transition-opacity`
