- Import `useState`, `useEffect`, `useCallback`, `useRef` from 'react'
- Import `EntityComparison` from `@/types`
- Constants: `API_BASE = '/api'`, `POLL_INTERVAL = 10_000` (10 seconds, 5x slower than dashboard)
- Export function `useSchemaComparison()` returning `{ data: EntityComparison[] | null, isLoading: boolean, error: string | null, refresh: () => void }`
- Token management: `const tokenRef = useRef<string | null>(null)`
- `getToken` async function: if `tokenRef.current` exists, return it; otherwise `fetch(\`${API_BASE}/setup/token\`, { method: 'POST' })`, parse JSON, store `body.token` in `tokenRef.current`, return it. Throw on non-ok response: `'Failed to obtain auth token'`.
- `fetchData` async function: call `getToken()`, then `fetch(\`${API_BASE}/schemas/compare\`, { headers: { Authorization: \`Bearer ${token}\` } })`. On 401 response: clear `tokenRef.current = null`, retry once (call `getToken()` again + re-fetch). If second attempt also fails, set error. On success: `setData(json)`, `setError(null)`. On any error: `setError(err.message || 'Failed to fetch schemas')`. Always `setIsLoading(false)` in finally block.
- `useEffect`: call `fetchData()` on mount, set `setInterval(fetchData, POLL_INTERVAL)`, return cleanup `clearInterval`.
- Return object: `{ data, isLoading, error, refresh: fetchData }`
