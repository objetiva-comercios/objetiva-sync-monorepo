## Decisions Made

1. **PM2 fork mode instead of cluster** - Sync module has stateful components (node-cron scheduler, sync queue, dashboard sessions) and uses SQLite which doesn't support concurrent writes. Fork mode with 1 instance is required.

2. **mkdir ./database/ with KNOWN COUPLING comment** - drizzle.config.ts hardcodes `./database/objetiva-sync.db` path and drizzle-kit reads this file directly, ignoring DATABASE_PATH env var. Deploy script creates both `$(dirname "$DATABASE_PATH")` and `./database/` directories with explicit comment documenting this coupling.

3. **ENCRYPTION_KEY and SESSION_SECRET not validated** - These secrets are auto-generated by the app on first run (see src/config/env.ts lines 96-113). Requiring them in deploy.sh validation would be redundant and error-prone.

4. **Git Bash compatibility constraints** - No `readlink -f` (not available in Git Bash), use `cd "$(dirname ...)" && pwd` pattern instead. Portable `mkdir -p` and `stat` commands.

5. **Spanish .env.example comments** - Matching existing codebase patterns where Spanish is used for user-facing configuration and documentation.
