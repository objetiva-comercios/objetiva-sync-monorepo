Create `deploy.sh` -- a bash deployment script for AlmaLinux with the following structure:

1. **Header**: `#!/bin/bash` with `set -euo pipefail`
2. **SCRIPT_DIR detection**: `cd` to script directory so paths are relative to project root
3. **Logging function**: `log()` that prefixes with timestamp, writes to both stdout and a deploy log file in `logs/deploy-YYYYMMDD-HHMMSS.log`
4. **Error handler**: `trap 'handle_error $LINENO' ERR` that logs failure line and exits
5. **validate_env_vars function**: Takes list of var names, checks each is set and non-empty via `${!var:-}`, collects all missing vars and reports them all at once before exiting
6. **Pre-flight checks**:
   - Node.js version >= 20 (parse `node -v`)
   - `npm` available
   - `pm2` available (with hint: `npm install -g pm2`)
   - `pg_dump` available (with hint: PostgreSQL client tools required)
7. **Load and validate environment**:
   - Check `.env` file exists, exit with clear error if not
   - `source .env` (NOT `export` -- the vars just need to be in the shell environment for the script and child processes inherit via PM2 ecosystem)
   - `validate_env_vars DATABASE_URL JWT_SECRET PORT NODE_ENV HOST SYNC_USERNAME SYNC_PASSWORD_HASH`
8. **Install dependencies**: `npm ci --production=false` (need devDeps for tsc and prisma)
9. **Generate Prisma Client**: `npx prisma generate`
10. **Build TypeScript**: `npm run build`, then verify `dist/` directory exists
11. **Database backup**:
    - Create `backups/` directory if not exists
    - Extract DB connection parts from DATABASE_URL using sed (host, port, user, password, dbname)
    - Run `pg_dump -Fc -Z 9` with PGPASSWORD to `backups/gateway-backup-YYYYMMDD-HHMMSS.dump`
    - Verify backup file exists and has size > 0
    - Clean up backups older than 7 days using `find -mtime +7 -delete`
12. **Run Prisma migrations**: `npx prisma migrate deploy`
13. **Start/reload PM2**:
    - If process `sync-gateway` already exists in PM2: `pm2 reload ecosystem.config.js --env production`
    - Else: `pm2 start ecosystem.config.js --env production`
    - Save PM2 process list: `pm2 save`
14. **Health check**: Sleep 3 seconds, then check if PM2 process is online (`pm2 describe sync-gateway`)
15. **Final log**: "Gateway deployment completed successfully" with hints for `pm2 logs` and `pm2 status`

Make script executable-ready (though on Windows we write it, on Linux the user runs `chmod +x deploy.sh`).

Create `ecosystem.config.js` -- PM2 ecosystem file:
- `name`: "sync-gateway"
- `script`: "./dist/server.js"
- `instances`: 1 (NOT cluster mode -- Fastify with SSE and stateful connections should run single instance)
- `exec_mode`: "fork"
- `env_production`: `{ NODE_ENV: "production" }`
- `watch`: false
- `autorestart`: true
- `max_memory_restart`: "512M"
- `min_uptime`: "10s"
- `max_restarts`: 10
- `error_file`: "./logs/pm2-error.log"
- `out_file`: "./logs/pm2-out.log"
- `log_date_format`: "YYYY-MM-DD HH:mm:ss Z"
- `merge_logs`: true

IMPORTANT: Do NOT use cluster mode. The gateway uses SSE (Server-Sent Events) for sync progress streaming and has stateful connections. Cluster mode would break SSE connections. Use fork mode with 1 instance.

**Enhance .env.example** -- Replace the current minimal file with a comprehensive documented template. Group variables by section with comment headers. Include ALL env vars used in the gateway source code:

Required:
- `PORT=3335` -- Server port (default: 3335)
- `NODE_ENV=production` -- Environment (development, production)
- `HOST=0.0.0.0` -- Listen address (0.0.0.0 for all interfaces, 127.0.0.1 for localhost only)
- `DATABASE_URL=` -- PostgreSQL connection string, format: postgresql://user:password@host:port/database
- `JWT_SECRET=` -- JWT signing secret, generate with: `openssl rand -hex 32`
- `JWT_EXPIRES_IN=86400` -- JWT expiration in seconds (default: 86400 = 24 hours). MUST be a number, not string.
- `SYNC_USERNAME=admin` -- Fixed username for sync client authentication
- `SYNC_PASSWORD_HASH=` -- Bcrypt hash of sync client password, generate with: `node -e "import('bcryptjs').then(b => console.log(b.hashSync('yourpassword', 10)))"`

Optional:
- `LOG_LEVEL=info` -- Logging level (error, warn, info, debug, trace)
- `APP_NAME=Objetiva Sync Gateway` -- Application name (displayed in setup page)
- `SYNC_ENTITIES=` -- Comma-separated list to override default entity list (leave empty for all)
