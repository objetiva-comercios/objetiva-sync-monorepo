2. Implement TYPE_MAPPING constant for type normalization:
   ```typescript
   const TYPE_MAPPING: Record<string, string> = {
     'character varying': 'varchar',
     'character': 'char',
     'integer': 'int',
     'smallint': 'int',
     'bigint': 'int',
     'timestamp without time zone': 'timestamp',
     'timestamp with time zone': 'timestamp',
     'double precision': 'float',
     'real': 'float',
     'numeric': 'decimal',
     'jsonb': 'jsonb',
     'json': 'jsonb',
     'ARRAY': 'array',
     'boolean': 'boolean',
     'text': 'text',
     'date': 'date',
     'time without time zone': 'time',
     'time with time zone': 'time',
     'uuid': 'uuid',
   };
   ```

3. Implement `normalizeType(dataType: string, udtName: string): string`:
   - If dataType is 'ARRAY', return 'array' (per context: base type only)
   - Otherwise lookup in TYPE_MAPPING, return original if not found

4. Implement `introspectColumns(schema: string, tableName: string): Promise<ColumnMetadata[]>`:
   - Query information_schema.columns with parameterized SQL
   - Use col_description() for column comments (with quote_ident for safety)
   - Convert is_nullable 'YES'/'NO' to boolean
   - Normalize data_type using normalizeType()
   - Store column_default as-is (expression string, not parsed)
   - Order by ordinal_position

5. Implement `introspectConstraints(schema: string, tableName: string): Promise<ConstraintMetadata[]>`:
   - Query information_schema.table_constraints joined with key_column_usage
   - Join referential_constraints and constraint_column_usage for FK details
   - Filter by constraint_type IN ('PRIMARY KEY', 'FOREIGN KEY', 'UNIQUE', 'CHECK')
   - Group by constraint_name (multi-column constraints return multiple rows)
   - Preserve column order via ordinal_position

6. Implement `getTableComment(schema: string, tableName: string): Promise<string | null>`:
   - Use obj_description() with regclass

7. Implement `introspectTable(schema: string, tableName: string): Promise<TableSchema>`:
   - Wrap in withRetry for connection resilience
   - Call introspectColumns, introspectConstraints, getTableComment
   - Return combined TableSchema object

8. Implement `introspectEntities(entityNames: string[], schema?: string): Promise<IntrospectionResult>`:
   - Default schema to 'public'
   - Process entities SEQUENTIALLY (per context: avoid pool exhaustion)
   - For each entity, try introspectTable with withRetry
   - On success, add to result.tables
   - On failure, add IntrospectionError to result.errors
   - Log each entity start/complete
   - Return partial results (successful + errors)

Import types from '../types/schema.js', pool from '../lib/db.js', retry from '../lib/retry.js', logger from '../lib/logger.js'.

Avoid:
- Do NOT query pg_catalog directly (use information_schema for portability)
- Do NOT cache results (always fresh per context)
- Do NOT process entities in parallel (sequential per context)
- Do NOT retry SQL syntax or permission errors (only connection errors)
- Do NOT parse column_default expressions (store as string)
