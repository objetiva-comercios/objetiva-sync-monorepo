**File 1: `src/services/sync-schema-store.ts`** (per D-04)

Create a module-level `Map<string, TableSchemaMetadata>` (not exported directly). Export a `syncSchemaStore` object with these methods:

```typescript
import type { TableSchemaMetadata } from '@shared/types/schema-metadata.js';

const store = new Map<string, TableSchemaMetadata>();

export const syncSchemaStore = {
  set(snapshots: TableSchemaMetadata[]): void {
    store.clear();
    for (const schema of snapshots) {
      store.set(schema.entity, schema);
    }
  },
  get(entity: string): TableSchemaMetadata | null {
    return store.get(entity) ?? null;
  },
  hasData(): boolean {
    return store.size > 0;
  },
  _resetForTest(): void {
    store.clear();
  },
};
```

**File 2: `src/services/schema-comparison.ts`** (per D-07, D-08, D-09, D-10)

Define these types (exported for use by routes and tests):

```typescript
export interface FieldLayerData {
  data_type: string;
  is_nullable: boolean;
}

export interface ComparisonFieldRow {
  column_name: string;
  status: 'aligned' | 'mismatched' | 'missing';
  postgresql: FieldLayerData | null;
  compiled: FieldLayerData | null;
  sync: FieldLayerData | null;
}

export interface EntityComparison {
  entity: string;
  sync_reported: boolean;
  summary: { aligned: number; mismatched: number; missing: number };
  fields: ComparisonFieldRow[];
}
```

Export function `buildEntityComparison(entity, pgSchema, compiledSchema, syncSchema, syncReported)`:

- `pgSchema`: `TableSchema | null` (from IntrospectionService — gateway type with `table_name`, `columns`, `constraints`)
- `compiledSchema`: `TableSchemaMetadata | null` (from shared/schemas/index.ts)
- `syncSchema`: `TableSchemaMetadata | null` (from syncSchemaStore)
- `syncReported`: `boolean`

Logic (per D-08, D-09):
1. If `pgSchema` is null (introspection failed), return entity with empty fields and all-zero summary.
2. Build a column map for compiled: `Map<column_name, {data_type, is_nullable}>` from `compiledSchema.columns`.
3. Build a column map for sync: `Map<column_name, {data_type, is_nullable}>` from `syncSchema?.columns` (empty map if syncSchema is null).
4. Iterate `pgSchema.columns`. For each column:
   - Extract `pg: { data_type, is_nullable }` from the PostgreSQL column
   - Look up `compiled` from the compiled column map (null if absent)
   - Look up `sync` from the sync column map (null if absent, OR null if `!syncReported`)
   - Determine status:
     - If `compiled === null` OR (`syncReported && sync === null`): status = `'missing'`
     - Else: compare `pg.data_type === compiled.data_type && pg.is_nullable === compiled.is_nullable`. If sync is participating (`syncReported`), also check `sync.data_type === pg.data_type && sync.is_nullable === pg.is_nullable`. If all checks pass: `'aligned'`, else `'mismatched'`.
5. Compute summary by counting statuses.
6. Return `{ entity, sync_reported: syncReported, summary, fields }`.

Import `TableSchema` from `../types/schema.js` for the pgSchema parameter type. Import `TableSchemaMetadata` from `@shared/types/schema-metadata.js` for compiled/sync parameter types.
