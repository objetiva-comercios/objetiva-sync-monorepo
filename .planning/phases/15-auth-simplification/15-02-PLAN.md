<task type="auto">
  <name>Task 2: Add Password Change Endpoint</name>
  <files>objetiva-sync-gateway/src/routes/auth.ts</files>
  <action>
Add POST /api/auth/change-password endpoint that requires authentication AND current password verification.

1. Define Zod schema for request:
```typescript
const ChangePasswordSchema = z.object({
  currentPassword: z.string().min(1, 'Current password is required'),
  newPassword: z.string().min(6, 'New password must be at least 6 characters')
});
```

2. Add the route with preHandler authentication:
```typescript
app.post('/api/auth/change-password', { preHandler: [authenticate] }, async (request, reply) => {
  // Implementation
});
```

3. Implementation flow:
   a. Parse and validate request body with ChangePasswordSchema
   b. Get current SYNC_PASSWORD_HASH from env
   c. Verify currentPassword against SYNC_PASSWORD_HASH using bcrypt.compare
   d. If verification fails, return 401 with error code PASSWORD_INVALID
   e. Hash newPassword with bcrypt (saltRounds = 10)
   f. Update .env file with new SYNC_PASSWORD_HASH (use same pattern as setup.ts)
   g. Return success with message about server restart

4. Error responses:
   - Current password wrong: `{ success: false, error: 'PASSWORD_INVALID', message: 'Current password is incorrect' }`
   - System not configured: `{ success: false, error: 'SYSTEM_NOT_CONFIGURED', message: 'Auth system not configured - run /setup first' }`

5. Success response:
```typescript
{
  success: true,
  message: 'Password changed successfully. Server restart required for changes to take effect.'
}
```

6. Copy the .env file update logic from setup.ts (read file, replace SYNC_PASSWORD_HASH line, write file).
