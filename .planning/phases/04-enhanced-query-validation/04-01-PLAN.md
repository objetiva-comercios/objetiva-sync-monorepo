   - GET /api/schemas/:entity

   - Return SchemaResponse or throw on error

4. **fetchAllSchemasFromGateway()** - Fetch all entity schemas:
   - GET /api/schemas

   - Return SchemaResponse[] or throw on error

   - 401 Unauthorized: "Gateway authentication failed - check GATEWAY_JWT_SECRET"
   - 404 Not Found: "Entity schema not found: {entity}"
   - Network error: "Gateway unreachable at {url}"
   - Include response body in error when available

Use native fetch (Node 18+ built-in). Do NOT use node-fetch or axios.

<task type="auto">
  <name>Task 3: Create schema cache service</name>
  <files>objetiva-sync/src/services/schema-cache.ts</files>
  <action>
Create a schema cache service following the gateway's pattern but adapted for sync:

1. **CacheEntry interface:**
   - schema: SchemaResponse
   - fetchedAt: number (timestamp)
   - expiresAt: number (timestamp)

2. **Configuration:**
   - TTL_MS = 60 * 60 * 1000 (1 hour, matching gateway)
   - Allow override via SCHEMA_CACHE_TTL_MS env var

3. **schemaCache object (singleton):**

   **getSchema(entity: string): Promise<SchemaResponse | null>**
   - Check cache for valid entry (not expired)
   - If valid, return cached schema
   - If expired or missing, fetch from gateway via gateway-client
   - On fetch success: cache new entry, return schema
   - On fetch error: return stale cache if available (graceful degradation), log warning
   - If no stale cache available: return null (don't throw)

   **getAllSchemas(): Promise<SchemaResponse[]>**
   - Fetch all schemas from gateway
   - Cache each one individually
   - Return array of schemas

   **invalidate(entity?: string): void**
   - If entity provided, delete that cache entry
   - If no entity, clear entire cache

   **size(): number**
   - Return number of cached entries

4. **initializeSchemaCache(): Promise<void>**
   - Called on sync service startup
   - Load all 4 entity schemas: articulos, comprobantes_cabecera, comprobantes_detalle, comprobantes_pagos
   - Log success/failure for each
   - Do NOT throw on failure (service should start even if gateway is down)

Use the logger from '../utils/logger.js' for all logging.
  </action>
  <verify>TypeScript compiles: `cd objetiva-sync && npx tsc --noEmit`</verify>
  <done>Schema cache fetches from gateway, caches with TTL, handles failures gracefully</done>
