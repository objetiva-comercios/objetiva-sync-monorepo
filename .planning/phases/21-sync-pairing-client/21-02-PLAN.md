<!-- From Plan 01: the claim proxy route contract -->

POST /api/config/pairing/claim:
- Request: { gatewayUrl: string, code: string }
- Response 200: { success: true, gatewayUrl: string }
- Response 400: { success: false, error: 'Faltan campos requeridos' }
- Response 404: { success: false, error: 'Codigo invalido o expirado' }
- Response 410: { success: false, error: 'Codigo ya fue utilizado' }
- Response 502: { success: false, error: 'No se pudo conectar al gateway' | specific message }

Existing JS functions in api.ejs (globally available):
- loadApiConfig() — fetches GET /api/config/api and populates form fields
- loadApiStatus() — htmx.ajax GET /api/config/api/status into #api-status-container
- testApiConnection() — POST /api/config/api/test, shows notification, refreshes status
- showNotification(message, type) — displays toast notification
</interfaces>
