    Current code at line 143-144:
    ```typescript
    // Sort lexicographically and return the max
    return values.sort().reverse()[0] ?? null;
    ```

    The problem: When incrementalType=id (numeric field), lexicographic sort gives wrong results (e.g., "9" > "10"). ISO date strings sort correctly lexicographically, but numeric IDs do not.

    Replace with logic that attempts numeric comparison first:
    ```typescript
    // Try numeric comparison first (for incrementalType=id), fall back to lexicographic (for dates/strings)
    const numericValues = values.map(Number);
    if (numericValues.every(n => !isNaN(n))) {
      return String(Math.max(...numericValues));
    }
    // Lexicographic sort works for ISO date strings
    return values.sort().reverse()[0] ?? null;
    ```
