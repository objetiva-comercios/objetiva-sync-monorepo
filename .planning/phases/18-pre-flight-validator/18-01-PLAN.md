<feature>
  <name>Centralized .env Writer with Async Mutex</name>
  <files>objetiva-sync-gateway/src/utils/env-writer.ts, objetiva-sync-gateway/tests/unit/env-writer.test.ts</files>
  <behavior>
    - writeEnvVar("KEY", "simple") writes KEY="simple" to .env
    - writeEnvVar("KEY", "p@$$#word") writes KEY="p@$$#word" — $ and # are safe inside double quotes
    - writeEnvVar("KEY", 'has"quote') writes KEY="has\"quote" — inner double-quote escaped
    - writeEnvVar("KEY", "has\\back") writes KEY="has\\back" — backslash escaped
    - writeEnvVar("KEY", "value") on existing KEY= line replaces only that line (regex anchored to line start with ^)
    - writeEnvVar("KEY", "value") on non-existent .env creates file with "# .env — Generated by Objetiva Sync Gateway\n" header
    - writeEnvVar("KEY", "value") on .env missing KEY= appends new line
    - After writeEnvVar completes, process.env["KEY"] === "value"
    - Two concurrent writeEnvVar calls (Promise.all) both succeed with both values in file
    - writeEnvVars({ K1: "v1", K2: "v2" }) writes both atomically (single lock acquisition)
    - If doWrite throws (e.g., permission error), subsequent writes are NOT permanently blocked (chain resets)
  </behavior>
  <implementation>
    Promise-chain mutex (8 lines). Always double-quote values. Escape inner " as \" and \ as \\. Use ^KEY= regex with 'm' flag for line-start anchoring. After fs.writeFile, set process.env[key]. Export writeEnvVar (single) and writeEnvVars (batch). No external dependencies.
  </implementation>
</feature>
