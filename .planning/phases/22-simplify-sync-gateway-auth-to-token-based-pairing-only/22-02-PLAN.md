    1. **Delete** `src/api-client/auth.ts` entirely (AuthManager class, TokenStatus interface, all login/refresh/token caching logic).

    2. **Refactor each batch client** (`articulos-client.ts`, `comprobantes-cabecera-client.ts`, `comprobantes-detalle-client.ts`, `comprobantes-pagos-client.ts`):
       - Remove `authManager` constructor parameter. Constructor takes only `baseUrl: string` and optional `dispatcher?: Dispatcher`.
       - Add `import { getJwtToken } from '../services/gateway-client.js';` at top.
       - In `sendBatch()` (or equivalent request method): replace `const token = await this.authManager.getToken()` with `const token = await getJwtToken()`.
       - Remove the `private authManager` field.

    3. **Refactor `src/api-client/index.ts` (APIClient class):**
       - Remove `import { AuthManager } from './auth.js'`.
       - Remove `private authManager: AuthManager` field.
       - Simplify `APIClientConfig`: remove `username` and `password` fields. Keep `baseUrl` and optional `dispatcher`/`agent`.
       - In constructor: remove `new AuthManager(...)` creation. Pass only `baseUrl` and `agent` to batch client constructors.
       - Remove or simplify `initialize()`: no more `authManager.login()` call. Can validate connectivity by calling a health endpoint with JWT if desired, or just mark as ready.
       - Remove or simplify `testConnection()`: use `getJwtToken()` + fetch `/health` with Bearer token instead of `authManager.login()`.
       - Remove `getToken()`, `hasValidToken()`, `logout()`, `getConnectionInfo()` methods that delegate to authManager.
       - Add `import { getJwtToken } from '../services/gateway-client.js'` if needed for test connection.

    4. **Update `src/sync/scheduler-instance.ts`:**
       - Remove password/username reading from SQLite config (REMOTE_API_PASSWORD, REMOTE_API_USERNAME decryption).
       - Create APIClient with simplified config: only `baseUrl` (read REMOTE_API_URL from SQLite).
       - If JWT_SECRET is not configured in SQLite, skip scheduling (log warning: "Gateway no enlazado, sync deshabilitado").

    5. **Update `src/sync/sync-engine.ts`:**
       - Update `APIClient` type references if the interface changed.
       - Ensure SyncEngine works with the simplified APIClient (no password in config).

    6. **Update `src/__tests__/api-client-metadata.test.ts`:**
       - Remove `mockAuthManager` creation and usage.
       - Update batch client instantiation: pass only `baseUrl` (no authManager).
       - Mock `getJwtToken` from `../services/gateway-client.js` instead of AuthManager.
       - Update assertions to match new constructor signatures.
