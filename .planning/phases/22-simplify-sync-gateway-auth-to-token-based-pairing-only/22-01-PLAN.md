<objective>
Remove password-based authentication from the gateway: delete auth routes, clean pairing claim response, add POST /api/setup/token endpoint, renumber setup wizard from 6 to 5 steps, update codegen script auth, clean env vars.

Purpose: Eliminate the redundant password credential layer. After pairing, sync signs JWTs locally with the shared JWT_SECRET. The gateway only needs to verify JWT signatures, not manage login/refresh flows.

Output: Gateway with JWT-only authentication, 5-step wizard, no SYNC_PASSWORD/SYNC_USERNAME references, all gateway tests passing.
</objective>
