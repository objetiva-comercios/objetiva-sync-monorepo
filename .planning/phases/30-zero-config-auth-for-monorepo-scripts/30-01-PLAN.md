## Objective

After pairing, the regenerate-schemas script (and any future monorepo scripts) authenticates automatically against the gateway without manual .env configuration.

## Tasks

1. **Modify codegen/index.ts** — Accept pre-obtained JWT via `JWT_TOKEN` env var (priority over `JWT_SECRET`)
2. **Modify regenerate-schemas.ts** — Auto-discover gateway URL from gateway's `.env` (GATEWAY_PUBLIC_URL), request JWT from gateway via `POST /api/setup/token`
3. **Update .env.example** — Mark GATEWAY_URL/JWT_SECRET as optional overrides
4. **Update DEPLOY.md** — Reflect zero-config in Paso 1-2 and troubleshooting

## Approach

Use the same auth mechanism as the dashboard: `POST /api/setup/token` is unauthenticated and returns a valid JWT. The script reads `GATEWAY_PUBLIC_URL` from the gateway's own `.env` file (written by the setup wizard during initial configuration), then requests a token. No secrets need to leave the gateway.

## Verification

- `SKIP_DOTENV=1 GATEWAY_URL=http://sync-gateway.sanchezrepuestos.com.ar npx tsx scripts/regenerate-schemas.ts --dry-run` succeeds with "Token obtained from gateway (auto-authenticated)"
- TypeScript compiles without errors (`npx tsc --noEmit`)
- Legacy flow (manual .env) still works as fallback
