```typescript
export interface ClassifiedError {
  code: string;
  message: string;
  isRetryable: boolean;
  rootCause: string;
}
```

Classification rules (check in this order):

1. **User cancellation** -- `error.name === 'AbortError'` AND error message does NOT contain 'timeout':
   - code: `SYNC_CANCELED`
   - message: `Sincronizacion cancelada por el usuario`
   - isRetryable: false
   - rootCause: `El usuario cancelo la operacion.`

2. **Explicit timeout (AbortSignal.timeout)** -- `error.name === 'TimeoutError'` OR (`error.name === 'AbortError'` AND error message contains 'timeout'):
   - code: `TIMEOUT_GATEWAY_REQUEST`
   - message: `Timeout al enviar batch al gateway (limite: 2 minutos)`
   - isRetryable: true
   - rootCause: `El gateway tardo mas de 2 minutos en procesar el batch. Puede estar sobrecargado o el batch es muy grande.`

3. **undici headers timeout** -- `error.name === 'HeadersTimeoutError'` OR message contains `UND_ERR_HEADERS_TIMEOUT`:
   - code: `TIMEOUT_GATEWAY_HEADERS`
   - message: `Gateway no respondio a tiempo (headersTimeout)`
   - isRetryable: true
   - rootCause: `El gateway tardo demasiado en responder. Puede estar sobrecargado.`

4. **undici body timeout** -- `error.name === 'BodyTimeoutError'` OR message contains `UND_ERR_BODY_TIMEOUT`:
   - code: `TIMEOUT_GATEWAY_BODY`
   - message: `Timeout al recibir respuesta del gateway`
   - isRetryable: true
   - rootCause: `El gateway esta procesando un batch muy grande. Intenta con batch size menor.`

5. **SQL Server timeout** -- message contains `Request failed to complete` OR `ETIMEOUT` OR `requestTimeout`:
   - code: `TIMEOUT_ERP_QUERY`
   - message: `Timeout al consultar ERP: ${original message}`
   - isRetryable: true
   - rootCause: `La consulta SQL al ERP tardo demasiado. Verifica la query o el estado del servidor ERP.`

6. **Connection refused** -- message contains `ECONNREFUSED`:
   - code: `GATEWAY_UNREACHABLE`
   - message: `Gateway no disponible: ${original message}`
   - isRetryable: true
   - rootCause: `El servicio gateway no esta ejecutandose o no es accesible.`

7. **Connection reset** -- message contains `ECONNRESET`:
   - code: `GATEWAY_CONNECTION_RESET`
   - message: `Conexion con gateway interrumpida`
   - isRetryable: true
   - rootCause: `La conexion fue cerrada inesperadamente. Puede ser un problema de red o el gateway se reinicio.`

8. **DNS resolution** -- message contains `ENOTFOUND` OR `EAI_AGAIN`:
   - code: `GATEWAY_DNS_ERROR`
   - message: `No se puede resolver la direccion del gateway`
   - isRetryable: false
   - rootCause: `Verifica que la URL del gateway es correcta y que hay conectividad de red.`

9. **HTTP 401/403** -- message contains `HTTP 401` OR `HTTP 403`:
   - code: `GATEWAY_AUTH_ERROR`
   - message: `Error de autenticacion con el gateway`
   - isRetryable: false
   - rootCause: `Las credenciales del gateway son invalidas o expiraron. Verifica usuario y contrasena en Configuracion.`

10. **HTTP 5xx** -- message matches `HTTP 5\d\d`:
    - code: `GATEWAY_SERVER_ERROR`
    - message: `Error interno del gateway: ${original message}`
    - isRetryable: true
    - rootCause: `El gateway tuvo un error interno. Revisa los logs del gateway.`

11. **Default/unknown** -- anything else:
    - code: `UNKNOWN_ERROR`
    - message: original error message or String(error)
    - isRetryable: false
    - rootCause: `Error no clasificado. Revisa los logs para mas detalles.`

Export the function and the interface. Use `export function classifyError(error: unknown): ClassifiedError`.

IMPORTANT: Do NOT use accented characters in the messages -- use plain ASCII Spanish (e.g., `sincronizacion` not `sincronizacion`) to avoid encoding issues in SSE and logs. Actually, review the existing codebase pattern -- if existing messages use accents (they do, e.g., `Sincronizacion cancelada`), then keep consistency and USE accents.

Check the existing pattern in the codebase: the code uses accent characters (e.g., `Sincronización cancelada por el usuario` in articulos-client.ts line 192). Follow the same pattern -- use proper Spanish with accents.
