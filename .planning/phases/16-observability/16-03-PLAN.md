Add sync-specific metrics to `src/lib/prometheus.ts`:

```typescript
import { exponentialBuckets } from 'prom-client'

// Sync operation duration histogram
// Buckets: 0.1s to 102.4s covering small batches to large syncs
export const syncDuration = new Histogram({
  name: 'sync_operation_duration_seconds',
  help: 'Duration of sync operations in seconds',
  labelNames: ['entity_type', 'source_id', 'sync_type'],
  buckets: exponentialBuckets(0.1, 2, 11), // [0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.4, 12.8, 25.6, 51.2, 102.4]
  registers: [register]
})

// Sync record counter
export const syncRecordsTotal = new Counter({
  name: 'sync_records_total',
  help: 'Total number of records processed',
  labelNames: ['entity_type', 'source_id', 'operation'], // operation: inserted, updated, failed
  registers: [register]
})
```

Note:
- Labels limited to 3 per metric to avoid cardinality explosion
- entity_type: articulo, comprobante_cabecera, comprobante_detalle, comprobante_pago
- source_id: from X-Origin-Source header (Phase 14)
- sync_type: batch (for duration histogram)
- operation: inserted, updated, failed (for record counter)

   - After processing, record metrics:
     ```typescript
     // Duration recorded automatically when end() called
     end()

     // Record counts
     syncRecordsTotal.inc({ entity_type: 'articulo', source_id: sourceId, operation: 'inserted' }, result.inserted)
     syncRecordsTotal.inc({ entity_type: 'articulo', source_id: sourceId, operation: 'updated' }, result.updated)
     syncRecordsTotal.inc({ entity_type: 'articulo', source_id: sourceId, operation: 'failed' }, result.failed)
     ```
   - Wrap in try/finally to ensure timer ends even on error:
     ```typescript
     const end = syncDuration.startTimer({...})
     try {
       // ... processing
       syncRecordsTotal.inc(...)
     } finally {
       end()
     }
     ```
