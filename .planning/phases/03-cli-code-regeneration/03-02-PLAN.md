  <action>
    Create `src/codegen/index.ts` - the main orchestrator function that coordinates the full regeneration pipeline.

    **Function: `regenerateSchemas(options: RegenerateOptions): Promise<RegenerateResult>`**

    Implementation steps:

    **Step 1: Pre-flight checks**
    - Check `GATEWAY_URL` env var. If missing, throw Error: `"E001: GATEWAY_URL environment variable not set. Set it to the gateway base URL (e.g., http://localhost:3001)."`
    - Check `SYNC_USERNAME` env var. If missing, throw Error: `"E002: SYNC_USERNAME environment variable not set. Required for gateway authentication."`
    - Check `SYNC_PASSWORD` env var. If missing, throw Error: `"E002: SYNC_PASSWORD environment variable not set. Required for gateway authentication."`
    - Load env vars from `.env` file using dotenv if available, or instruct user to set them. Actually, since the gateway already uses dotenv, check if `dotenv` is installed. If not, rely on process.env directly and document that env vars must be set.
    - IMPORTANT: Check if dotenv is in gateway dependencies. If YES, import and call `dotenv.config()` at the start. If NO, just use process.env directly. Looking at gateway package.json - dotenv is NOT listed. So use process.env directly. The CLI script (not the orchestrator) should load .env manually using `import { config } from 'dotenv'` only if dotenv is available, or read .env file with fs.readFileSync and parse manually. SIMPLEST approach: Add `dotenv` as a dev dependency OR document that user must set env vars. Since the sync module uses dotenv, and this is a developer tool, add dotenv to devDependencies.

    **Step 2: Authenticate with gateway**
    - POST to `${GATEWAY_URL}/auth/login` with body `{ username: SYNC_USERNAME, password: SYNC_PASSWORD }`
    - Extract JWT token from response `{ token: string }`
    - If auth fails, throw Error: `"E003: Authentication failed. Check SYNC_USERNAME and SYNC_PASSWORD credentials."`
    - Use native `fetch` (Node 20+ has it built-in)

    **Step 3: Determine entities to process**
    - If `options.entity` is set, validate it's in the sync entities list (import getSyncEntities from config/entities.js)
    - If not a valid entity, throw Error: `"E004: Unknown entity '${entity}'. Valid entities: ${entities.join(', ')}"`
    - Otherwise, use all entities from getSyncEntities()

    **Step 4: Fetch all schemas (fail fast)**
    - For each entity, fetch from `${GATEWAY_URL}/api/schemas/${entity}` with `Authorization: Bearer ${token}` header
    - Parse response as SchemaResponse
    - If any fetch fails, throw immediately (all-or-nothing per CONTEXT.md decision)
    - Print progress: `chalk.cyan(`Fetching schema for ${entity}...`)`

    **Step 5: Generate all content**
    - Call `generatePrismaSchema(schemas)` to get complete schema.prisma content
    - For each schema, call `generateZodSchema(schema)` to get Zod file content
    - Build array of GeneratedFile objects with entity name, content, and target file path
    - Prisma path: `resolve(process.cwd(), 'prisma/schema.prisma')`
    - Zod paths: `resolve(process.cwd(), 'shared/schemas/generated', `${entity}.generated.ts`)`

    **Step 6: Compute all diffs**
    - Read existing files (if they exist) using readFileSync
    - Call computeDiff for each file (prisma + each zod file)
    - Collect all DiffResult objects

    **Step 7: Display diffs (sequential per entity, per CONTEXT.md decision)**
    - For each DiffResult with changes, call displayDiff()
    - Call displaySummary() for overall summary

    **Step 8: Write files (unless dry-run)**
    - If `options.dryRun`: print chalk.yellow('\n--dry-run: No files were modified.') and return
    - Create `shared/schemas/generated/` directory if it doesn't exist (mkdirSync with recursive: true)
    - Write all files using writeFileSync
    - Print chalk.green(`Written: ${filePath}`) for each file

    **Step 9: Run prisma generate (CLI-03 requirement)**
    - Only if NOT dry-run and schema.prisma was written
    - Run `npx prisma generate` via execSync with cwd set to gateway root
    - Capture output, print success/failure
    - If prisma generate fails, throw Error: `"E005: prisma generate failed. ${error.message}"`

    **Step 10: Return result**
    - Return RegenerateResult with hasChanges, filesWritten count, entitiesChecked count, diffs array

    **Import dotenv:** Add `dotenv` to devDependencies: `npm install --save-dev dotenv`. In the orchestrator's authenticate function, do NOT call dotenv.config() - that's the CLI entry point's job.

    **2. Create `scripts/regenerate-schemas.ts`:**
    Standalone CLI entry point that parses arguments and calls the orchestrator.

    ```typescript
    #!/usr/bin/env node
    // CLI tool for regenerating Prisma and Zod schemas from PostgreSQL
    // Usage: npm run regenerate-schemas [-- --dry-run] [-- --entity <name>]

    import { config } from 'dotenv';
    import { resolve } from 'node:path';
    import { regenerateSchemas } from '../src/codegen/index.js';

    // Load .env from gateway root directory
    config({ path: resolve(import.meta.dirname, '..', '.env') });

    // Parse CLI arguments
    const args = process.argv.slice(2);
    const dryRun = args.includes('--dry-run');
    const entityIndex = args.indexOf('--entity');
    const entity = entityIndex !== -1 ? args[entityIndex + 1] : undefined;

    // Validate --entity has a value
    if (entityIndex !== -1 && !entity) {
      console.error('Error: --entity flag requires a value (e.g., --entity articulos)');
      process.exit(1);
    }

    async function main() {
      console.log('Schema Regeneration Tool');
      console.log('========================\n');

      if (dryRun) {
        console.log('Mode: DRY RUN (no files will be modified)\n');
      }

      if (entity) {
        console.log(`Entity filter: ${entity}\n`);
      }

      try {
        const result = await regenerateSchemas({ dryRun, entity });

        if (result.hasChanges) {
          console.log(`\nRegeneration complete. ${result.filesWritten} file(s) updated.`);
        } else {
          console.log(`\nValidated ${result.entitiesChecked} entities, no changes needed.`);
        }

        process.exit(0);
      } catch (error) {
        console.error(`\n${error instanceof Error ? error.message : String(error)}`);
        process.exit(1);
      }
    }

    main();
    ```
