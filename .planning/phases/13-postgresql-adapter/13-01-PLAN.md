2. Create `objetiva-sync/src/adapters/postgresql/postgresql-adapter.ts`:

   Follow SQLServerAdapter pattern exactly. Key differences for PostgreSQL:

   - Use `pg.Pool` instead of `mssql.ConnectionPool`
   - Config schema uses `host` (not `server`), default port 5432
   - Add SSL config: `ssl: { enabled: boolean, rejectUnauthorized: boolean }`
   - Parameter conversion: Replace `@paramName` with `$1`, `$2` positional params
   - Information schema queries use PostgreSQL syntax (table_schema || '.' || table_name)
   - Test query: `SELECT version() as version` instead of `@@VERSION`
   - Sample data: `SELECT * FROM {table} LIMIT {n}` instead of `SELECT TOP`

   Config schema (from RESEARCH.md):
   ```typescript
   const postgresConfigSchema = z.object({
     host: z.string().min(1, 'El host es requerido'),
     port: z.number().int().min(1).max(65535).default(5432),
     database: z.string().min(1, 'La base de datos es requerida'),
     user: z.string().min(1, 'El usuario es requerido'),
     password: z.string().min(1, 'La contrasena es requerida'),
     ssl: z.object({
       enabled: z.boolean().default(false),
       rejectUnauthorized: z.boolean().default(true),
     }).optional(),
     connectionTimeout: z.number().int().min(1000).default(30000),
   });
   ```

   Parameter conversion in doExecuteQuery:
   - Parse params object, assign $1, $2, etc. to each key
   - Replace @paramName or :paramName in SQL with corresponding $N
   - Pass values array to pool.query()

   Pool error handler:
   ```typescript
   this.pool.on('error', (err) => {
     logger.error(err, '[PostgreSQL] Pool error on idle client');
   });
   ```
