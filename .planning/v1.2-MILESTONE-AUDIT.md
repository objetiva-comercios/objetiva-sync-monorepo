## Cross-Phase Integration

### CRITICAL: Wizard Pairing Step Auth Broken

**Break:** `POST /api/setup/token` returns 403 after `apply-config` transitions `startupMode` to `'normal'`

**Trace:**
1. Wizard step 3 (Apply Config) calls `POST /api/setup/apply-config`
2. `setup.ts:1381-1382` sets `systemState.startupMode = 'normal'`
3. Wizard auto-advances to step 4 (Link Sync Client)
4. `enterPairingStep()` calls `POST /api/setup/token`
5. Token endpoint checks `startupMode !== 'setup-only'` — now TRUE → returns 403
6. Pairing code generation fails (no JWT token)

**Affected requirements:** AUTH-RM-04, AUTH-RM-05, PAIR-01, PAIR-02
**File:** `objetiva-sync-gateway/src/routes/setup.ts` (lines 941, 976-991, 1381-1382, 1510-1516)

**Fix options:**
- (A) Move token acquisition to JWT step (step 2), before apply-config
- (B) Change `/api/setup/token` to allow a brief grace period after mode transition
- (C) Have apply-config return a token in its response

### MEDIUM: Missing fast-jwt Dependency in Sync

`objetiva-sync/src/services/gateway-client.ts:11` imports `createSigner` from `fast-jwt` but `fast-jwt` is not in `objetiva-sync/package.json`. Works via monorepo hoisting, fails in isolated install.

**Affected requirements:** AUTH-RM-06
**Fix:** Add `fast-jwt` to `objetiva-sync/package.json` dependencies.

### LOW: Preflight Data Unused in Wizard

Wizard DOMContentLoaded fetches `/api/setup/preflight` but discards the result (`void preflight`). Wasted network request.
