### Integration Issue

**STALE-DIST-001:** `objetiva-sync/dist/` was last built 2026-02-13 (before Phase 26). The `reportSchemasToGateway()` function exists in source but is absent from the production dist bundle. Running `npm start` without rebuilding first means sync never reports schemas to the gateway, causing Schema Status page to permanently show `sync_reported: false`.

- **Severity:** Deployment risk (not a code break)
- **Affected requirement:** SCHEMA-04
- **Mitigation:** Run `npm run build` in `objetiva-sync/` before deploying
